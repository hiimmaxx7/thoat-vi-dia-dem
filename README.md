# Thoát vị đĩa đệm

Dành cho người ngồi nhiều đau lưng.

**[⬇ Tải extension cho Chrome (.zip)](https://github.com/hiimmaxx7/thoat-vi-dia-dem/releases/download/v1.0.1/thoat-vi-dia-dem-1.0.1.zip)**

Extension phát video bài học ở tốc độ 16× và tự chuyển sang video kế tiếp trên trang bài học tương thích.

## Cài vào Chrome

1. Bấm **Tải extension cho Chrome** ở trên.
2. Mở thư mục **Tải xuống**, nhấp chuột phải vào file ZIP và chọn **Giải nén tất cả** (**Extract All**).
3. Dán `chrome://extensions` vào thanh địa chỉ Chrome rồi nhấn Enter.
4. Bật **Chế độ dành cho nhà phát triển** (**Developer mode**) ở góc trên bên phải.
5. Bấm **Tải tiện ích đã giải nén** (**Load unpacked**), chọn thư mục **thoat vi dia dem** vừa giải nén rồi bấm **Chọn thư mục**. Nếu có hai thư mục lồng nhau, chọn thư mục bên trong có file `manifest.json`.

## Dùng khi học

1. Mở trang bài học có video.
2. Bấm biểu tượng **Tiện ích** hình mảnh ghép cạnh thanh địa chỉ, rồi chọn **Thoát vị đĩa đệm**.
3. Bấm **Tua nhanh 16×**. Nếu video chưa phát, bấm **Play** trên video.
4. Hết video, extension chờ 1,5 giây rồi mở video kế tiếp. Bấm **Dừng tua** để đưa tốc độ về 1×. Extension tự dừng khi đến cuối danh sách hoặc gặp mục khác.
