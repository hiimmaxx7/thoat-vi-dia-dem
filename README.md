# Thoát vị đĩa đệm

Dành cho người ngồi nhiều đau lưng.

Extension Chrome phát video bài học ở tốc độ 16× và tự chuyển sang video kế tiếp.

## Cài đặt

1. Mở repo trên GitHub, chọn **Code → Download ZIP**, rồi giải nén.
2. Mở `chrome://extensions` và bật **Chế độ dành cho nhà phát triển**.
3. Bấm **Tải tiện ích đã giải nén** (**Load unpacked**) và chọn thư mục chứa `manifest.json`.

## Sử dụng

1. Mở trang bài học có video. Bấm biểu tượng **Thoát vị đĩa đệm** trên thanh công cụ Chrome.
2. Bấm **Tua nhanh 16×**. Nếu Chrome chặn tự phát, bấm **Play** trên video.
3. Khi phát hết video, extension chờ 1,5 giây rồi mở video kế tiếp. Extension tự dừng khi gặp mục khác hoặc hết danh sách. Bấm **Dừng tua** để đưa tốc độ về 1× bất cứ lúc nào.

Extension cần trang bài học dùng iframe `#course_lesson_iframe` cùng origin và cấu trúc danh sách bài tương thích.
